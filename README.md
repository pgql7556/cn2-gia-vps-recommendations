## 購買前要檢查的五件事

### 1. 先確認實際 ISP，而不是只看地理位置

「離中國近」不代表所有 ISP 都更快。先確認主要訪客是電信、聯通還是移動，再看測試 IP 或官方路由資料。

### 2. 不要只比較 CPU 和 RAM

CN2 GIA VPS 的價格差異很大，真正拉開差距的往往包括：

- 中國方向的路由
- 月流量額度
- 機房位置
- 網路連接速度
- 是否能免費遷移機房
- 是否包含快照和自動備份
- 是否提供 IPv6
- 是否有 SLA 或 uptime guarantee

### 3. 看清楚計費週期

20G 和 40G 方案主要提供季付、半年付和年付。80G 以上則普遍有月付選項。不要只看年付平均月成本，也要注意一次性付款金額和退款政策。

### 4. 確認它是自主管理 VPS

BandwagonHost 的相關方案標示為 strictly self-managed。這表示你需要自行處理：

- Linux 更新
- SSH 安全
- 防火牆
- Web 伺服器
- 資料庫
- 備份驗證
- 監控與故障排查

如果你只想要「開通後有人幫忙維護」，這類 VPS 可能不是最省事的選擇。

### 5. CN2 GIA 不等於免受攻擊或封鎖

官方 CN2 GIA 說明也提到，CN2 GIA 容量有限，對 DDoS 攻擊的容忍度並不高，遭遇攻擊時可能需要進行 IP nullrouting。

所以，如果服務是公開網站或 API，建議至少配置：

- SSH 金鑰登入並關閉密碼登入
- 防火牆和 fail2ban
- 定期異地備份
- Web 應用程式防火牆
- 基本監控和告警
- 獨立的備份驗證流程

線路好，不代表可以忽略安全設定。網路品質和主機安全是兩件事。
